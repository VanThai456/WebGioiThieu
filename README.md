# 🌟 Hệ Thống White-Label Landing Page (React + Vite + Tailwind CSS)

Hệ thống Landing Page cao cấp áp dụng cơ chế **White-label thực thụ** (tách rời 100% nội dung & cấu hình giao diện ra khỏi mã nguồn).

## 🚀 Cách Chạy Dự Án
```bash
npm run dev
```

## 🔄 Chuyển Đổi Giao Diện:
- Bấm nút **`[ 🎨 Đổi giao diện (1/3) ]`** gắn ngay cạnh bong bóng Zalo ở góc phải màn hình để xoay vòng **Mẫu 1 ➔ Mẫu 2 ➔ Mẫu 3 ➔ Mẫu 1**.
- Hoặc thêm tham số URL: `?brand=cafe&v=1`, `?brand=product&v=2`, `?brand=corporate&v=3`.
